# Concur 경비 자동 입력

휴대폰으로 찍은 영수증 사진(아이폰·갤럭시 등 상관없음)을 읽어서 Concur 지난달 리포트를 만들고, 경비마다 영수증 첨부와 필드 입력을 한 뒤 저장까지 합니다.
단축어 없이 **카메라로 찍기만** 해도 됩니다. 파일 이름과 형식(jpg, heic)은 상관없고, 영수증이 아닌 사진은 자동으로 뺍니다.
어느 달 영수증인지는 **영수증에 적힌 날짜**로 정하므로, 영수증을 한 달 뒤에 찍어도 됩니다.
**제출은 하지 않습니다.** 결과를 확인하고 직접 제출하세요.

## 영수증 사진 넣는 방법

영수증 사진이 있는 곳은 프로그램 창의 **[영수증 불러오기] 탭**에서 넣습니다. **여러 곳을 넣어도 되고**, 폴더 안의 하위 폴더까지 찾습니다.

| 탭에서 할 수 있는 것 | 설명 |
|---|---|
| **폴더 추가 ▾** | 누르면 이 PC에서 찾은 곳(iCloud 사진, iCloud Drive 영수증 폴더, OneDrive 갤럭시 사진, OneDrive 카메라 앨범, 구글 드라이브, 카카오톡 받은 파일, 다운로드)이 나옵니다. 고르면 바로 들어갑니다. 맨 아래 **다른 폴더 직접 고르기…**로 아무 폴더나 넣을 수도 있습니다. |
| **사진 가져오기…** | USB로 옮긴 사진, 이메일·메신저로 받은 사진 등 **아무 곳의 사진**을 골라 `문서\Concur 경비 자동 입력\가져온 영수증` 폴더에 복사합니다(원본은 그대로, 날짜 정보 유지). 이 폴더는 자동으로 목록에 들어갑니다. |
| **폴더 열기 / 빼기** | 목록에서 고른 폴더를 탐색기로 열거나 목록에서 뺍니다. 빼도 폴더와 사진은 지우지 않습니다. |
| **이 달 사진** | 탭을 열거나 폴더를 바꾸면 폴더마다 처리할 달 영수증일 수 있는 사진 수를 자동으로 셉니다(글자는 읽지 않아 빠름). 폴더를 잘 골랐는지 볼 때 쓰세요. |

- 같은 사진(이름·크기가 같음)이 여러 폴더에 있으면 한 번만 씁니다. 하지만 같은 영수증을 다른 방법으로 두 번 넣으면(예: iCloud 원본 + 카카오톡으로 받은 사본) 두 장으로 보일 수 있으니 한 가지 방법만 쓰세요.
- 파일 이름의 날짜도 읽습니다: `2026-10-22_123342.jpg`(단축어), `20261022_123342.jpg`(갤럭시), `IMG_20261022_123342.jpg`(안드로이드), `KakaoTalk_20261022_…`(카카오톡).

### 아이폰이 아닌 휴대폰 (갤럭시 등)
- **갤럭시 + OneDrive:** 갤러리 앱 → 설정 → **OneDrive와 동기화**를 켜면, PC의 OneDrive 사진 폴더(`OneDrive\사진\Samsung Gallery`)로 사진이 들어옵니다. PC에도 같은 Microsoft 계정으로 OneDrive에 로그인한 뒤, 탭의 '이 PC에서 찾은 곳'에서 **OneDrive 갤럭시 사진**을 추가하세요.
- **구글 드라이브:** 휴대폰에서 영수증을 구글 드라이브에 올리고, PC에 '구글 드라이브' 앱을 설치하면 생기는 폴더(보통 `G:\내 드라이브`)를 추가합니다. (구글 포토는 PC 폴더로 내려오지 않습니다.)
- **카카오톡:** '나와의 채팅'으로 영수증 사진을 보낸 뒤 PC 카카오톡에서 저장하면 `문서\카카오톡 받은 파일` 폴더에 들어갑니다. 이 폴더를 추가하세요. **'원본'으로 보내야** 사진이 작아지지 않아 글자가 잘 읽힙니다.
- **USB 케이블·이메일:** 사진을 PC에 옮기거나 내려받은 뒤 **[사진 가져오기…]**로 가져옵니다.

### 아이폰 (아래 셋 중 하나)

#### 방법 1. 카메라로 찍기만 하기 (가장 간단)
iPhone 카메라로 찍으면 iCloud 사진으로 올라가고 PC로도 자동으로 내려옵니다.
1. iPhone: 설정 → 맨 위 내 이름 → iCloud → 사진 → **이 iPhone 동기화** 켜기 (대부분 이미 켜져 있습니다)
2. PC: Microsoft Store에서 **iCloud**를 설치하고 로그인한 뒤 **사진**을 체크합니다.
3. 프로그램 창의 [영수증 불러오기] 탭 → **[폴더 추가 ▾]**에서 **iCloud 사진**을 고릅니다. 목록에 없으면 탐색기 왼쪽의 **iCloud 사진**을 열어 폴더 경로(보통 `C:\Users\<사용자 이름>\Pictures\iCloud Photos\Photos`)를 확인하고 [폴더 추가 ▾] → 다른 폴더 직접 고르기…로 고릅니다.

- 폴더에 가족 사진 같은 일반 사진이 섞여 있어도 됩니다. 지난달에 찍은 사진만 보고, 영수증이 아닌 것은 자동으로 뺍니다.
- **주의:** 이 방법은 iPhone의 사진이 모두 회사 PC로 내려옵니다. 회사 PC에 개인 사진을 두기 꺼려지거나 회사 정책상 안 되면 방법 2를 쓰세요.

#### 방법 2. iCloud Drive 폴더에 넣기
찍은 뒤 사진 앱에서 공유 → **파일에 저장** → iCloud Drive의 `Concur_Expenses` 폴더에 저장합니다. 영수증만 PC로 갑니다.
- 프로그램이 처음부터 이 폴더(`C:\Users\<사용자 이름>\iCloudDrive\Concur_Expenses`)를 보도록 되어 있어 따로 바꿀 필요가 없습니다.
- 여러 장을 한꺼번에 골라 저장해도 되고, 늦게 저장해도 됩니다. 어느 달 영수증인지는 영수증에 적힌 날짜로 정합니다.
- 기본 폴더 이름과 조금 달라도(예: `Concur_Expense`) iCloud Drive 안에 Concur로 시작하는 폴더가 하나뿐이면 처음 실행할 때 그 폴더를 자동으로 고릅니다. 다르면 [영수증 불러오기] 탭에서 고르세요.

#### 방법 3. 지금 쓰는 단축어 그대로
`2026-10-22_123342.jpg`처럼 저장하는 기존 단축어도 그대로 됩니다.

**사진 형식:** iPhone 기본 형식(HEIC)도 읽습니다. Concur에는 JPEG로 바꿔서 올립니다.

## 처음 한 번

1. 이 폴더를 PC에 두고 명령 프롬프트에서 설치합니다.
   ```
   python -m pip install -r requirements.txt
   ```
   (브라우저는 PC의 Edge를 쓰므로 `playwright install`은 필요 없습니다.)
2. `python concur_auto.py`를 실행하면 창이 열립니다.
3. 창의 **[영수증 불러오기] 탭**에서 영수증 사진이 있는 폴더를 넣고, [실행] 탭에서 **기본 도시**(▼에서 고르거나, Concur 도시 목록에 보이는 이름 그대로 적기), **Concur 로그인 이메일**(회사 이메일)을 확인합니다.
4. **[병원 목록 편집]**에서 담당 병원과 영문 이름을 확인합니다. 영수증에서 새 병원이 보이면 자동으로 더합니다. 자세한 것은 아래 '병원 찾기'를 보세요.
   - 처음에는 영수증에서 확인한 병원(원광대병원 `Wonkwang University Hospital`, 목포한국병원 `Mokpo Hankook Hospital`)만 들어 있습니다. 예전 기본 목록(동료분의 대전·충청권)은 자동으로 지웁니다(직접 넣으신 줄은 그대로).
   - 여러 글자가 맞으면 긴 글자가 우선합니다. 짧은 글자는 다른 병원에도 걸립니다(예: `남대`는 `전남대`에도 맞음).
   - OCR이 자주 틀리게 읽는 글자(예: 충남대 → 중남대)도 한 줄 더 넣어 두면 됩니다.

## 병원 찾기

영수증마다 병원을 아래 순서로 찾습니다. 영수증 목록과 결과 파일의 `병원 근거` 칸에 어디서 찾았는지 나옵니다.

1. **영수증 글자:** 영수증에 찍힌 병원 이름을 `병원목록.csv`에서 찾습니다. 목록에 없어도 영수증에 'OO병원'·'OO의료원'이 보이면 그 이름을 쓰고, 영문 이름을 자동으로 만들어 병원 목록에 더합니다(예: 목포한국병원 → `Mokpo Hanguk Hospital`).
2. **Concur 가게 이름:** Concur에 입력할 때, 카드 결제의 가게 이름(예: `WON GWANG DAE HAK GYO BYUNG WON`)이 병원이면 그 병원을 씁니다.
3. **같은 날 영수증:** 같은 날 다른 영수증(보통 주차)에서 찾은 병원을 카페·식대 영수증에도 씁니다. 같은 날 병원이 여러 곳이면 주차 영수증의 병원을 쓰고, 그래도 여러 곳이면 비워 둡니다.

셋 다 못 찾으면 병원 칸을 비워 두고 Comment에서 ` in 병원` 부분을 뺍니다. 병원 이름이 없는 영수증이 많아서 '확인 필요'로 묻지 않고 그대로 진행합니다.

### 병원 목록 편집 창
[실행] 탭의 **[병원 목록 편집]**을 누르면 엑셀 대신 편집 창이 열립니다.
- **왼쪽 목록:** 찾을 글자와 영문 이름. 점 색깔: 파랑 = 괜찮음, **주황 = 자동으로 만든 영문 이름이라 확인 필요**, 회색 = 영문 이름이 비어 있음. **찾기**로 줄일 수 있습니다.
- **오른쪽:** `영수증에서 찾을 글자`(예: `원광대`)와 `Concur에 쓸 영문 이름`(예: `Wonkwang University Hospital`)을 고칩니다. 주황 점 병원은 공식 영문 이름과 같으면 **[영문 이름 확인함]**을 누르고, 다르면 고치면 됩니다(고치면 저절로 확인됨). 확인하거나 고친 이름은 병원 엑셀을 다시 읽어도 바뀌지 않습니다.
- **[새 병원]·[삭제]**, **[저장]**하면 다음 실행부터 씁니다. 저장할 때 같은 찾을 글자, 빈 영문 이름, 너무 짧은 찾을 글자가 있으면 알려 줍니다. 엑셀이 편하면 **[엑셀로 열기]**도 있습니다.

### 병원 정보 엑셀에서 가져오기 (창의 버튼은 없앴습니다)
프로그램 창을 간단하게 하려고 [병원 엑셀 가져오기] 버튼은 없앴습니다. 예전에 이 버튼으로 엑셀을 골라 둔 적이 있으면, 실행할 때마다 그 엑셀에서 새 병원을 계속 자동으로 더합니다. 다시 쓰고 싶으면 설정 파일(`concur_settings.json`, `문서\Concur 경비 자동 입력` 폴더에 있음, 메모장으로 열기)의 `병원_엑셀_파일`에 엑셀 경로를 적으세요.
1. 회사 SharePoint의 병원 정보 엑셀(MR·CT·XR 탭이 있는 파일)을 PC에 받습니다(SharePoint 문서 폴더의 **동기화**를 쓰면 바뀌면 따라 바뀜).
2. 설정 파일의 `병원_엑셀_파일`에 그 파일 경로를 적습니다. 경로의 `\`는 `\\`처럼 두 번 씁니다.
3. 실행할 때 MR·CT·XR 탭을 모두 읽어 새 병원을 `병원목록.csv`에 더합니다(예전 'MR System Information' 탭도 읽습니다).
   - 탭에 영문 병원 이름 열(Hospital, University, Medical Center 등이 든 영어)이 있으면 그 이름을 그대로 씁니다. 자동으로 만든 영문명도 엑셀 영문명으로 바꿉니다(직접 고친 이름은 그대로).
   - 영문 이름은 한글을 자동으로 바꾼 것입니다(예: 원광대학교병원 → `Wongwang University Hospital`). 공식 영문명과 다를 수 있으니 [병원 목록 편집]에서 주황 점 병원을 확인하고 고치세요. 고친 이름은 다시 가져와도 바뀌지 않습니다.
   - `OCR에서 찾을 글자`는 병원 이름에서 '학교병원', '병원' 등을 뺀 글자입니다(예: `원광대`). 영수증에 자주 다르게 찍히는 이름이 있으면 한 줄 더 넣으세요.
4. 그다음부터는 실행할 때마다 그 엑셀에서 새 병원만 자동으로 더합니다.

- 병원 이름 열은 자동으로 고릅니다. 다른 열이 잡히면 설정 파일의 `병원_엑셀_열`에 열 제목(예: `병원명`)이나 열 문자(예: `C`)를 적으세요.
- **이 엑셀은 회사 자료입니다. GitHub 등 밖으로 올리지 마세요.** 프로그램은 PC 안에서만 읽습니다.

| 주차 | 주차, 입차, 출차, 주자, 입출차, 파킹, 발렛, parking, valet | Parking & Toll |

- 영어 글자(hotel 등)는 대소문자 상관없이 찾습니다. 한 글자짜리나 지명과 겹치는 글자(예: 부산 해운대구 '우동')는 다른 영수증에도 맞을 수 있어 넣지 않았습니다.
- 이미 쓰던 자동입력표에는 새 판을 처음 실행할 때 새 기본 글자(식대·숙박, 그다음 카페·주차)를 **한 번만** 더합니다(쓰시던 글자·문구는 그대로, 숙박 항목이 없으면 식대 아래에 넣음). 그 뒤에 지운 글자는 다시 넣지 않습니다.

**글자 찾기보다 똑똑하게 (PC 안에서, 사진이 밖으로 나가지 않음):**
- **가게 기억:** 영수증에 찍힌 **사업자등록번호**로 가게를 알아봅니다. [영수증 확인]에서 어떤 가게 영수증의 분류·병원·도시를 한 번 고르고 저장하면, 다음부터 **같은 가게 영수증은 그대로 맞춥니다**(찾을 글자보다 먼저). 엑셀로 고친 것도 다음 실행 때 기억합니다. 영수증 확인 창 '확인할 것'에 "(기억해 둔 가게…)"로 나옵니다. 기억은 `가게기억.json`에 저장되고 백업에도 들어갑니다.
- **카드 가맹점 이름:** 영수증 글자로 분류를 못 했으면, Concur 카드 경비에 찍힌 가맹점 이름(예: `STARBUCKS KOREA`, `KAKAO T PARKING`, `LOTTE HOTEL`)으로 분류합니다.

- **왼쪽 목록**에서 항목을 고르고 **오른쪽**에 적은 뒤 **[저장]**을 누르면 됩니다.
- 오른쪽 칸은 항목 이름·영수증에서 찾을 글자 다음에, **Concur 경비 화면과 같은 순서**(위에서 아래)로 있습니다. Concur에도 이 순서대로 넣습니다.

  | 칸 | 넣는 값 | 비워 두면 |
  |---|---|---|
  | Expense Type | Concur에 Undefined(비어 있음)일 때 고를 항목(▼로 Concur 목록에서 고름). 카드로 이미 들어와 있으면 그대로 둠 | 그대로 두고 '확인 필요' |
  | Business Purpose | 문구 | 넣지 않음 |
  | City | 이 항목은 늘 이 도시로(▼로 고름) | **(영수증 주소에서 찾기)**: 영수증 주소의 도시, 못 찾으면 기본 도시 |
  | LCRT | ▼로 고름 | `NA` |
  | Receipt Status | 영수증을 붙일 때 고를 값 | `Receipt` |
  | Personal Expense | 체크하면 Concur의 Personal Expense (do not reimburse)를 체크 | 건드리지 않음 |
  | Comment | 문구. `{hospital}` 자리에 병원 영문명 | 넣지 않음 |

  Transaction Date·Amount·Currency는 카드 정보로 들어와 있어 건드리지 않습니다. Concur에 이미 맞는 값이 들어 있는 칸도 건드리지 않습니다.
- **항목 이름은 한글로 마음대로 적습니다**(예: 톨게이트, 택시, 주유). 영수증 목록의 `분류` 칸에 이 이름이 나옵니다. **[새 항목]**을 누르면 '새 항목' 줄이 생기고 이름 칸이 골라져 있으니 바로 이름을 적으면 됩니다.
- **어느 항목에도 맞지 않는 영수증·영수증 없는 경비**는 Expense Type을 Undefined 그대로 두고 결과 파일 '확인 필요'에 "Expense Type 직접 고르기"로 남깁니다(예전의 '어느 항목에도 안 맞을 때 Expense Type'은 없앴습니다. 자동 입력 편집에서 항목을 만들어 두면 필요 없음).
- ● = 설정된 항목(영수증에 맞춰짐), ○ = 아직 안 한 항목. **[설정한 항목만 보기]**, **찾기**로 목록을 줄일 수 있습니다.
- **[새 항목]**·**[삭제]**·**▲▼**(순서: 위쪽 항목이 먼저 맞춰짐). 저장할 때 같은 이름, 여러 항목에 같은 찾을 글자, 문구가 빈 항목이 있으면 알려 줍니다.
- 엑셀로 한꺼번에 고치고 싶으면 **[엑셀로 열기]**(`자동입력표.csv`, 한 줄이 한 항목)를 쓰세요.

표의 칸은 이렇습니다.

| 칸 | 뜻 | 예 |
|---|---|---|
| 분류 | 항목 이름 | `주차`, `톨게이트` |
| 영수증에서 찾을 글자 | 영수증에 이 글자가 있으면 이 항목(쉼표로 여러 개) | `통행료, 톨게이트, 하이패스` |
| Comment | Concur Comment에 넣을 문구 | `Toll fee for service in {hospital}` |
| Business Purpose | Concur Business Purpose에 넣을 문구 | `For service` |
| Expense Type이 Undefined일 때 | Expense Type이 비어 있으면 고를 유형(Concur 목록에 보이는 이름 그대로) | `Parking & Toll` |
| City(비우면 영수증 주소) | 이 항목은 늘 이 도시로 | `Mokpo, KOREA, REPUBLIC OF` |
| LCRT / Receipt Status | Concur에서 고를 값(비우면 `NA` / `Receipt`) | `NA` / `Receipt` |
| Personal Expense(O면 체크) | O면 Personal Expense 체크 | `O` |

- **문구 고치기:** 해당 칸을 고치고 저장하면 다음 실행부터 바뀝니다.
- **새 항목 더하기:** 줄을 하나 더 쓰면 됩니다. 영수증 목록의 `분류` 칸에도 그 이름을 적을 수 있습니다.
- **위에 있는 줄이 먼저 맞춰집니다.** 한 영수증에 여러 항목의 글자가 있으면 위쪽 항목이 됩니다.
- `{hospital}`(또는 `{병원}`) 자리에 병원 영문명이 들어갑니다. 병원을 못 찾으면 ` in {hospital}`/` at {hospital}` 부분은 빠집니다.
- 예전 판이 만든 맨 아래 `(분류 없음)` 줄은 이제 쓰지 않습니다(있어도 무시하고, 저장하면 없어집니다).
- 이미 Concur에 들어간 경비는 **② 전체 실행**을 다시 누르고 "이어서 넣기"를 고르면 새 문구로 다시 입력됩니다(이미 첨부된 영수증은 다시 올리지 않음).
- **Concur 항목 목록:** 사용자 Concur 화면에서 캡처한 Expense Type 47개(Accommodation, Meals & Drinks, Taxi, Phone & Fax, M card … 항목 등)가 모두 들어 있어 편집 창의 Expense Type ▼에서 고르면 됩니다. Concur에서는 이름이 **완전히 같은** 항목만 고르므로 비슷한 이름(예: `Accommodation`과 `M card accommodation`)이 헷갈리지 않습니다. Concur에 항목이 새로 생기면 캡처해서 Claude에게 보내 주세요.

## 백업·되살리기 (새 판으로 바꿀 때)

자동 입력 편집에서 만든 규칙, 병원 목록, 설정, 영수증 목록은 **`문서\Concur 경비 자동 입력` 폴더**의 개인 파일(`자동입력표.csv`, `병원목록.csv`, `concur_settings.json`, `가게기억.json`, `결과`·`실행기록`·`가져온 영수증` 폴더)에 저장되고, **다음 실행부터 바로** 쓰입니다. 이 파일들은 내 PC에만 있고 프로그램 파일 안에 들어가지 않습니다. 프로그램(exe)을 바탕화면 등 어디에 두어도 그 옆에는 파일이 생기지 않습니다.

- **새 판으로 바꾸는 방법:** 프로그램 파일(`concur_auto.py` 또는 exe)만 새 것으로 바꾸면 됩니다. 어느 폴더에 두든 같은 `문서\Concur 경비 자동 입력` 폴더를 쓰므로 규칙도 그대로 쓰입니다.
- **예전 판에서 바꿀 때:** 예전 판은 exe 옆(예: 바탕화면)에 파일을 만들었습니다. 새 판을 그 자리에서 처음 켜면 그 파일들을 `문서\Concur 경비 자동 입력`으로 **옮기고**(바탕화면에서 없어짐), 실행 기록에 "개인 파일을 … 옮겼습니다"라고 남깁니다. 엑셀에 열려 있어 못 옮긴 파일이 있으면 닫고 다시 켜세요.
- **자동 백업:** 프로그램을 켤 때, 끌 때, 자동 입력을 저장할 때 바뀐 것이 있으면 `문서\Concur 경비 자동 입력 백업` 폴더에 zip 파일로 저장합니다(최근 20개). 이 폴더는 따로 있어서 `문서\Concur 경비 자동 입력` 폴더를 지워도 남습니다.
- **새 PC 등 설정이 없을 때:** 처음 켤 때 "예전 설정 되살리기"를 물어봅니다. [예]를 누르면 최근 백업으로 규칙·병원 목록·설정이 돌아옵니다.
- **[백업·되살리기] 탭:** 백업 목록(만든 시각, 자동/직접, 프로그램 판)을 보고 **[지금 백업하기]**, **[고른 백업 되살리기]**, **[다른 백업 파일에서 되살리기…]**(예: 다른 PC나 USB에 둔 백업)를 할 수 있습니다.
- 되살리기 전 상태도 자동으로 백업하므로, 잘못 되살렸으면 목록의 '자동 (되살리기 전)' 백업을 다시 되살리면 됩니다.
- 백업 폴더를 바꾸려면 설정 파일의 `백업_폴더`에 경로를 적습니다.
- 백업에는 영수증 사진, 실행 기록, 화면 캡처는 들어가지 않습니다(사진은 영수증 폴더에 그대로 있음).

## Concur 화면이 바뀌었을 때

Concur가 바뀌어 입력칸이나 버튼 위치가 달라지면 그 경비에서 오류가 나고, 결과 파일 `오류` 칸과 실행 기록에 **"'Comment' 칸을 찾지 못했습니다"**처럼 어느 칸인지 나옵니다(화면 캡처도 `실행기록` 폴더에 남습니다).

- **위치만 바뀌고 칸 이름(Comment, Business Purpose, Amount 등)이 그대로면** 프로그램이 칸 이름으로 다시 찾으므로 대부분 그냥 됩니다.
- **가장 쉬운 방법:** `문서\Concur 경비 자동 입력\실행기록` 폴더(기록 파일과 화면 캡처)를 Claude에게 보내 고쳐 달라고 하세요. 이 저장소의 `CLAUDE.md`에 지금까지의 내용이 정리돼 있어 이어서 고칠 수 있습니다.
- **버튼 글자가 바뀌었으면** 설정 파일(`concur_settings.json`, `문서\Concur 경비 자동 입력` 폴더에 있음, 메모장으로 열기)의 `화면_문구`에 새 글자를 `|`로 덧붙입니다. 예: `"경비 저장": "경비 저장|Save Expense|Save"`
- **입력칸 위치가 바뀌었으면** 화면 조사로 고칠 수 있습니다(창의 버튼은 없앴고, Python으로 실행할 때만 됩니다).
  1. 명령 프롬프트에서 `python concur_auto.py --inspect`를 실행합니다. 전용 Edge 창이 열리고 로그인됩니다.
  2. 문제가 생긴 Concur 화면(예: 경비 편집 화면)을 열고 [확인]을 누릅니다. 다른 화면도 조사하려면 그 화면을 열고 다시 [확인], 끝나면 [취소].
  3. `실행기록\화면조사_날짜.txt`가 생깁니다. 맨 위 표에서 **'없음'**으로 나온 칸이 지금 화면에서 못 찾는 칸입니다(다른 화면의 칸은 '없음'이 정상).
  4. 아래 `[이 화면의 입력칸]` 목록에서 칸 이름으로 그 칸을 찾아 `#id`를 확인하고, 설정 파일의 `화면_요소`에서 그 칸의 값을 바꿉니다. 예: Comment 칸이 `#txtComment`로 바뀌었으면 `"Comment": "#txtComment"`
  5. 직접 고치기 어려우면 `화면조사_날짜.txt`와 같은 이름의 `.png`, 실행 기록 파일을 Claude에게 보내 고쳐 달라고 하세요. 이 저장소의 `CLAUDE.md`에 지금까지의 내용이 정리돼 있어 이어서 고칠 수 있습니다.

## 매달 쓰는 순서

| 버튼 | 하는 일 |
|---|---|
| ① 영수증 분석만 | 사진의 글자만 읽고 **영수증 확인 창**을 엽니다. Concur는 열지 않습니다. |
| ② 전체 실행 | 리포트 생성 → 지난달 경비 추가 → 경비마다 영수증 첨부·입력 → 저장 |

**이미 만든 리포트가 있으면:** ②는 먼저 Concur 리포트 목록에서 같은 이름(예: `Monthly Expense for Nov`)의 리포트를 찾습니다. 있으면 **"이어서 넣기 / 새 리포트 만들기 / 중단"**을 물어봅니다.
- **이어서 넣기:** 그 리포트를 열어, 이미 들어 있는 경비에 영수증 첨부·입력을 이어서 합니다(이미 첨부된 경비는 건너뜀). 빈 리포트면 그 달 경비부터 넣습니다. 중간에 멈췄을 때 다시 하기에도 씁니다.
- 새로 들어온 카드 경비는 Concur에서 그 리포트에 넣은 뒤 ②를 다시 누르면 이어서 입력합니다.
- 리포트 목록에서 못 찾으면 새로 만듭니다(같은 이름이 둘이 되면 하나를 Concur에서 지우세요).

**리포트 만들기(②):** Concur의 [경비 리포트 생성] 화면에 이렇게 넣습니다(11월 예).

| 칸 | 넣는 값 |
|---|---|
| Report Name | `Monthly Expense for Nov` (달만 바뀜: Oct, Dec …) |
| From Date / To Date | `11/01/2026` / `11/30/2026` (그 달 1일 ~ 말일) |
| Business Purpose | `service` |
| Comment | Report Name과 같음 (`Monthly Expense for Nov`) |
| Policy, Cost Object Type, Cost Object | 손대지 않음 (Concur가 미리 넣은 값 그대로) |

바꾸고 싶으면 설정 파일의 `리포트_이름_형식`, `리포트_Business_Purpose`, `리포트_Comment_형식`을 고치세요.

**처리할 달:** 창 맨 위에서 고릅니다. 처음에는 지난달이 골라져 있고, 목록 맨 위에서 **이번 달**도 고를 수 있습니다.
- 이번 달은 아직 끝나지 않아서, Concur에 아직 들어오지 않은 경비와 앞으로 받을 영수증은 빠집니다. 시험해 보거나 미리 넣어 둘 때 쓰세요.
- 달이 끝난 뒤에는 남은 경비를 Concur에서 그 리포트에 추가하고 ②를 누른 뒤 "이어서 넣기"를 고르면 됩니다. 이미 첨부된 경비는 업로드를 건너뜁니다.

**영수증 확인 창 (엑셀 대신):** ①이 끝나면 영수증 확인 창이 뜹니다. [실행] 탭의 **[영수증 확인]**으로도 엽니다.
- **왼쪽**은 영수증 목록(상태·날짜·금액·분류)입니다. 상태: ✓ 괜찮음 · ⚠ 확인 필요 · ✎ 고침 · ✕ 뺌. **[확인 필요만 보기]**로 고칠 것만 볼 수 있습니다.
- **가운데**에 그 영수증 사진이 나옵니다. **[사진 크게 보기]**로 사진을 크게 엽니다.
- **오른쪽**에서 틀린 곳만 고르거나 고칩니다.
  - **사용:** 체크를 끄면 Concur에 넣지 않습니다(영수증이 아닌 사진 등). 이 달 영수증이 아니라 자동으로 뺀 사진도, 영수증이 맞으면 체크하세요.
  - **날짜·금액:** ▼에 사진에서 읽은 후보가 있어 고르면 됩니다. 직접 적어도 됩니다(날짜는 `2026-10-27`처럼).
  - **분류:** 자동 입력 편집에서 만든 항목 중에서 고릅니다. 그 항목의 Comment·Expense Type 등이 들어갑니다.
  - **병원(영문)·도시:** 병원 목록·도시 목록에서 고르거나 적습니다. 도시를 '(기본 도시)'로 두면 기본 도시(광주)를 씁니다.
  - **Comment:** 서비스 오더 번호나 그 외 Comment에 들어갈 정보를 적습니다. Concur의 Comment **맨 뒤에** 한 칸 띄고 붙습니다. 예: 주차 영수증에 `SO 1234567`을 적으면 `Parking fee for service in Wonkwang University Hospital SO 1234567`.
  - **확인할 것:** 날짜 못 읽음 / 금액 못 읽음 / 분류 없음 / 같은 날짜·금액 영수증 있음 / 다른 달 영수증 / 영수증 아닌 것 같음 등 (병원 이름이 없는 것은 묻지 않습니다)
- **[저장]**하면 다음 실행부터 고친 내용을 씁니다(`결과\영수증목록_2026-10.csv`에 저장됨). 엑셀이 편하면 **[엑셀로 열기]**도 있습니다.
- 한 번 읽은 영수증은 다시 읽지 않아 두 번째 실행부터 빠릅니다.

②를 누를 때 확인이 필요한 영수증이 있으면, Concur에 넣기 전에 물어봅니다. [예]를 누르면 영수증 확인 창이 뜨고, 고친 뒤 창을 닫으면 이어서 진행합니다.

**끝나면** `결과\경비처리_2026-10.csv`가 열립니다. `확인 필요` 칸에 있는 경비만 Concur에서 보면 됩니다.
- 영수증 없음
- 분류 없음(영수증만 첨부), Expense Type 직접 고르기(맞는 자동 입력 항목 없음)
- 같은 날짜·금액 영수증 여러 장
- 금액 못 읽은 영수증을 날짜로 첨부 (그날 금액을 못 읽은 영수증이 한 장뿐이라 날짜만 보고 붙임)
- Expense Type 자동 선택
- 오류: `실행기록` 폴더에 화면 캡처가 남습니다.

## 알아 둘 점

- **로그인:** ②를 누르면 이 프로그램 전용 Edge 창이 열립니다.
  - 이미 로그인돼 있으면 바로 진행합니다.
  - 로그인 화면과 로그인 메일이 영어(Sign In / Next, "Sign-In Request to SAP Concur")로 나와도 됩니다.
  - Edge가 "페이지의 영어를 번역하시겠습니까?" 창을 띄우면 [더 보기] → **영어 번역 안 함**을 한 번 고르세요. 이 프로그램 창에서는 다음부터 뜨지 않습니다. 그냥 두어도 동작에는 지장이 없습니다.
  - 로그인 화면이 나오면 자동으로 [다음] → [이메일 링크로 로그인]을 누르고, Outlook에 온 "SAP Concur 로그인 요청" 메일의 링크를 **이 프로그램의 Edge 창에서** 엽니다. 메일은 보통 10초 안에 오고, 최대 2분까지 기다립니다.
  - 이메일 칸이 비어 있으면 창의 **Concur 로그인 이메일**에 적은 주소를 넣습니다. 비워 두면 Edge 창에서 직접 입력하면 됩니다.
  - **메일의 [SAP Concur 로그인] 버튼은 직접 누르지 마세요.** 누르면 평소 쓰는 Edge 창에서 열려 이 프로그램 창은 로그인되지 않고, 한 번만 쓸 수 있는 링크도 써 버리게 됩니다.
  - Outlook에서 메일을 못 찾으면(새 Outlook을 쓰는 경우 등) 링크를 붙여 넣는 창이 뜹니다. 메일의 버튼을 마우스 오른쪽으로 눌러 [하이퍼링크 복사]를 고른 뒤 붙여 넣으세요.
  - Outlook이 "다른 프로그램이 접근하려고 한다"는 경고를 띄우면 [허용]을 누르세요.
  - 자동 로그인을 끄려면 창의 **이메일 링크로 자동 로그인** 체크를 끄세요. 그러면 Edge 창에서 직접 로그인할 때까지 기다립니다(최대 10분).
- **실행 중:** 열린 Edge 창은 클릭하지 마세요. 다른 프로그램은 써도 되고, 창 위치나 크기는 상관없습니다.
- **멈추고 싶을 때:** 프로그램 창을 닫으면 됩니다(Edge 창도 닫힙니다). Concur에 이미 저장된 경비는 그대로 남고, 다음에 ②에서 "이어서 넣기"로 계속할 수 있습니다.
- **끝난 뒤:** ②가 끝나도 Edge 창은 닫지 않습니다. Concur에서 확인·수정한 뒤 **Edge 창을 직접 닫으면** 끝납니다(닫아야 ①② 버튼이 다시 눌립니다). 실행 기록 오른쪽 위에 "● 실행 중… / ● 준비됨"이 나옵니다. 예전처럼 자동으로 닫으려면 설정 `작업_후_Edge_열어두기`를 `false`로.
- **넣을 경비가 없을 때:** Concur에 사용 가능한 경비가 없거나(No Available Expenses), 그 달 경비가 없거나, 이어서 넣을 리포트에 경비가 없으면 오류 없이 "넣을 경비 없음" 안내를 띄우고 작업을 끝냅니다. Concur 창은 그대로 두니 필요하면 직접 경비를 만들거나 나중에 다시 실행하세요.
- **영수증 첨부:** 오른쪽 영수증 칸이 늦게 떠도 최대 15초 기다렸다가 [새 영수증 업로드]/[Upload New Receipt]로 올립니다. 버튼을 못 찾으면 건너뛰지 않고 결과 파일 '확인 필요'에 "영수증 첨부 버튼을 못 찾음"으로 남기고 화면을 저장합니다.
- **글자 입력:** Comment 같은 글은 한꺼번에 넣습니다(칸이 받지 않으면 한 글자씩). 예전처럼 한 글자씩 치려면 설정 `글자_입력_방식`을 `한 글자씩`으로.
- **보정:** 영수증 사진은 그대로 읽습니다. 금액이나 날짜를 못 읽은 영수증만 보정(대비·선명하게)해서 한 번 더 읽고, 더 잘 읽힐 때만 그 결과를 씁니다. 보정 사진은 임시로 만들었다가 바로 지웁니다(예전 판은 영수증마다 큰 png를 `Concur_Expenses_Processed` 폴더에 남겼는데, 이 폴더는 지워도 됩니다). 창의 체크를 끄면 보정하지 않습니다.
- **업로드 파일:** 원본 사진을 올립니다. HEIC는 JPEG로 바꾸고, Concur 제한(1장 5MB)을 넘으면 자동으로 줄인 사본을 올립니다.
- **도시:** 영수증 주소(예: `익산시`, `광주광역시`, `목포시`)나 병원 이름(예: 목포한국병원)에서 도시를 찾아 Concur 도시를 고릅니다. 같은 날 다른 영수증의 도시도 씁니다. 못 찾으면 기본 도시 `Gwangju (ex Kwangju), KOREA, REPUBLIC OF`를 고릅니다. 카드 정보로 다른 도시(예: Seoul)가 미리 들어가 있어도 영수증이 있는 경비는 이렇게 맞춥니다. 주차 회사 본사처럼 영수증에 서울 주소가 찍혀도 다른 도시가 있으면 그 도시를 씁니다. 찾을 도시 목록은 설정 파일의 `도시_목록`에서 고칠 수 있습니다.
  - 주소에 '시'가 없어도 찾습니다(예: `전북 익산 무왕로`, `대전 유성구`). 광주·전라의 시·군은 모두 목록에 있습니다(영암, 장성, 담양, 진도 등).
  - 찾은 도시가 Concur 도시 목록에 없으면 기본 도시(광주)를 고르고 '확인 필요'에 남깁니다. 도시나 Expense Type을 못 골라도 영수증 첨부는 계속합니다.
- **금액 읽기:** `6,000`, `6000원` 말고도 `주차요금 6000`처럼 쉼표 없이 금액 글자 뒤에 찍힌 숫자, OCR이 0을 O로 읽은 `6,0OO`도 읽습니다. 날짜는 `26.11.03`, `거래일시 20261103`도 읽습니다.
- **어느 달 영수증인지:** 영수증에 적힌 날짜로 정합니다. 그래서 영수증을 한 달 뒤에 찍어도 됩니다. 처리할 달이 끝나고 60일 안에 찍은 사진까지 봅니다(설정 `영수증_촬영_허용_일수`). 촬영 날짜는 영수증 날짜를 못 읽었을 때만 참고합니다.
- **Undefined인 Expense Type:** 자동 입력 편집의 항목에 정한 Expense Type을 고릅니다. 맞는 항목이 없으면 Undefined 그대로 두고 '확인 필요'로 표시합니다.
- **기타 설정:** `concur_settings.json`(메모장)에서 바꿉니다. 영수증 판별 글자, 도시 목록, Concur 화면 문구, 로그인 설정이 있습니다. 항목별 찾을 글자·Comment·Business Purpose·Expense Type은 `자동입력표.csv`에서 고칩니다.

## exe로 만들기

`build_exe.bat`을 더블클릭하면 `dist\ConcurAuto.exe`가 생깁니다. 콘솔 창 없이 바로 창이 뜹니다.
설정 파일, 병원 목록, `결과`·`실행기록` 폴더는 exe 옆이 아니라 `문서\Concur 경비 자동 입력` 폴더에 생깁니다. exe는 바탕화면 등 어디에 두어도 됩니다.
