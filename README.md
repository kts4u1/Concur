# Concur 경비 자동 입력

iPhone으로 찍은 영수증 사진을 읽어서 Concur 지난달 리포트를 만들고, 경비마다 영수증 첨부와 필드 입력을 한 뒤 저장까지 합니다.
단축어 없이 **카메라로 찍기만** 해도 됩니다. 파일 이름과 형식(jpg, heic)은 상관없고, 영수증이 아닌 사진은 자동으로 뺍니다.
어느 달 영수증인지는 **영수증에 적힌 날짜**로 정하므로, 영수증을 한 달 뒤에 찍어도 됩니다.
**제출은 하지 않습니다.** 결과를 확인하고 직접 제출하세요.

## 영수증 사진 넣는 방법 (셋 중 하나)

### 방법 1. 카메라로 찍기만 하기 (가장 간단)
iPhone 카메라로 찍으면 iCloud 사진으로 올라가고 PC로도 자동으로 내려옵니다.
1. iPhone: 설정 → 맨 위 내 이름 → iCloud → 사진 → **이 iPhone 동기화** 켜기 (대부분 이미 켜져 있습니다)
2. PC: Microsoft Store에서 **iCloud**를 설치하고 로그인한 뒤 **사진**을 체크합니다.
3. 탐색기 왼쪽의 **iCloud 사진**을 열어 주소창의 폴더 경로를 확인합니다. 보통 `C:\Users\<사용자 이름>\Pictures\iCloud Photos\Photos`입니다. 이 폴더를 프로그램 창의 **영수증 폴더**로 고릅니다.

- 폴더에 가족 사진 같은 일반 사진이 섞여 있어도 됩니다. 지난달에 찍은 사진만 보고, 영수증이 아닌 것은 자동으로 뺍니다.
- **주의:** 이 방법은 iPhone의 사진이 모두 회사 PC로 내려옵니다. 회사 PC에 개인 사진을 두기 꺼려지거나 회사 정책상 안 되면 방법 2를 쓰세요.

### 방법 2. iCloud Drive 폴더에 넣기
찍은 뒤 사진 앱에서 공유 → **파일에 저장** → iCloud Drive의 `Concur_Expenses` 폴더에 저장합니다. 영수증만 PC로 갑니다.
- 프로그램이 처음부터 이 폴더(`C:\Users\<사용자 이름>\iCloudDrive\Concur_Expenses`)를 보도록 되어 있어 따로 바꿀 필요가 없습니다.
- 여러 장을 한꺼번에 골라 저장해도 되고, 늦게 저장해도 됩니다. 어느 달 영수증인지는 영수증에 적힌 날짜로 정합니다.
- 기본 폴더 이름과 조금 달라도(예: `Concur_Expense`) iCloud Drive 안에 Concur로 시작하는 폴더가 하나뿐이면 처음 실행할 때 그 폴더를 자동으로 고릅니다. 다르면 창의 [찾기]로 고르세요.

### 방법 3. 지금 쓰는 단축어 그대로
`2026-10-22_123342.jpg`처럼 저장하는 기존 단축어도 그대로 됩니다.

**사진 형식:** iPhone 기본 형식(HEIC)도 읽습니다. Concur에는 JPEG로 바꿔서 올립니다.

## 처음 한 번

1. 이 폴더를 PC에 두고 명령 프롬프트에서 설치합니다.
   ```
   python -m pip install -r requirements.txt
   ```
   (브라우저는 PC의 Edge를 쓰므로 `playwright install`은 필요 없습니다.)
2. `python concur_auto.py`를 실행하면 창이 열립니다.
3. 창에서 **영수증 폴더**(위의 방법 1~3 중 쓰는 폴더), **기본 도시**(Concur 도시 목록에 보이는 이름 그대로), **Concur 로그인 이메일**(회사 이메일)을 확인합니다.
4. **[병원 목록 편집]** → 엑셀에서 `OCR에서 찾을 글자` / `Concur에 쓸 영문명`을 담당 병원으로 고치고 저장합니다.
   - 기본값은 대전·충청권 병원입니다.
   - 여러 글자가 맞으면 긴 글자가 우선합니다. 짧은 글자는 다른 병원에도 걸립니다(예: `남대`는 `전남대`에도 맞음).
   - OCR이 자주 틀리게 읽는 글자(예: 충남대 → 중남대)도 한 줄 더 넣어 두면 됩니다.

## 매달 쓰는 순서

| 버튼 | 하는 일 |
|---|---|
| ① 영수증 분석만 | OCR만 하고 **영수증 목록**(엑셀)을 엽니다. Concur는 열지 않습니다. |
| ② 전체 실행 | 리포트 생성 → 지난달 경비 추가 → 경비마다 영수증 첨부·입력 → 저장 |
| ③ 만든 리포트에 입력만 | 이미 있는 리포트를 열어 두면 영수증 첨부·입력만 합니다. 중간에 멈췄을 때 다시 하기에도 씁니다. 이미 첨부된 경비는 업로드를 건너뜁니다. |

**처리할 달:** 창 맨 위에서 고릅니다. 처음에는 지난달이 골라져 있고, 목록 맨 위에서 **이번 달**도 고를 수 있습니다.
- 이번 달은 아직 끝나지 않아서, Concur에 아직 들어오지 않은 경비와 앞으로 받을 영수증은 빠집니다. 시험해 보거나 미리 넣어 둘 때 쓰세요.
- 달이 끝난 뒤에는 남은 경비를 Concur에서 그 리포트에 추가하고 ③을 누르면 이어서 넣습니다. 이미 첨부된 경비는 업로드를 건너뜁니다.

**영수증 목록 고치기:** ①을 누르면 `결과\영수증목록_2026-10.csv`가 엑셀로 열립니다.
- `확인 필요` 칸에 날짜 못 읽음 / 금액 못 읽음 / 분류 없음 / 병원 없음 / 같은 날짜·금액 영수증 있음이 표시됩니다.
- 이 달 영수증이 아닌 사진은 맨 아래에 `사용` X로 있고, `확인 필요` 칸에 이유가 적혀 있습니다.
  - `날짜 못 읽음: 영수증 날짜를 적어 주세요`: `날짜` 칸에 영수증 날짜를 적고 저장하면 다음 실행부터 씁니다.
  - `다른 달 영수증(날짜)`: 날짜를 잘못 읽은 것이면 `날짜` 칸을 고치세요.
  - `영수증 아닌 것 같음`: 영수증이 맞으면 `사용`을 O로 바꾸세요.
- `촬영 시각` 칸으로 어떤 사진인지 찾을 수 있습니다. 파일 이름이 `IMG_1234.HEIC`처럼 나와도 됩니다.
- `날짜`, `금액`, `분류`(주차/카페/식대), `병원 영문`을 고치거나 `사용`을 X로 바꾸고 저장하면, 다음 실행부터 고친 값을 씁니다.
- 오른쪽 `[자동]` 칸은 프로그램이 비교용으로 쓰니 그대로 두세요.
- 한 번 OCR한 영수증은 다시 OCR하지 않아 두 번째 실행부터 빠릅니다.

②를 누를 때 확인이 필요한 영수증이 있으면, Concur를 열기 전에 목록을 열어 고칠 기회를 줍니다.

**끝나면** `결과\경비처리_2026-10.csv`가 열립니다. `확인 필요` 칸에 있는 경비만 Concur에서 보면 됩니다.
- 영수증 없음
- 분류 없음(영수증만 첨부)
- 병원명 없음
- 같은 날짜·금액 영수증 여러 장
- Expense Type 자동 선택
- 오류: `실행기록` 폴더에 화면 캡처가 남습니다.

## 알아 둘 점

- **로그인:** ②③을 누르면 이 프로그램 전용 Edge 창이 열립니다.
  - 이미 로그인돼 있으면 바로 진행합니다.
  - 로그인 화면이 나오면 자동으로 [다음] → [이메일 링크로 로그인]을 누르고, Outlook에 온 "SAP Concur 로그인 요청" 메일의 링크를 **이 프로그램의 Edge 창에서** 엽니다. 메일은 보통 10초 안에 오고, 최대 2분까지 기다립니다.
  - 이메일 칸이 비어 있으면 창의 **Concur 로그인 이메일**에 적은 주소를 넣습니다. 비워 두면 Edge 창에서 직접 입력하면 됩니다.
  - **메일의 [SAP Concur 로그인] 버튼은 직접 누르지 마세요.** 누르면 평소 쓰는 Edge 창에서 열려 이 프로그램 창은 로그인되지 않고, 한 번만 쓸 수 있는 링크도 써 버리게 됩니다.
  - Outlook에서 메일을 못 찾으면(새 Outlook을 쓰는 경우 등) 링크를 붙여 넣는 창이 뜹니다. 메일의 버튼을 마우스 오른쪽으로 눌러 [하이퍼링크 복사]를 고른 뒤 붙여 넣으세요.
  - Outlook이 "다른 프로그램이 접근하려고 한다"는 경고를 띄우면 [허용]을 누르세요.
  - 자동 로그인을 끄려면 창의 **이메일 링크로 자동 로그인** 체크를 끄세요. 그러면 Edge 창에서 직접 로그인할 때까지 기다립니다(최대 10분).
- **실행 중:** 열린 Edge 창은 클릭하지 마세요. 다른 프로그램은 써도 되고, 창 위치나 크기는 상관없습니다.
- **중지:** 지금 처리 중인 경비를 마치고 그 화면에서 저장한 뒤 멈춥니다.
- **업로드 파일:** 원본 사진을 올립니다. HEIC는 JPEG로 바꾸고, Concur 제한(1장 5MB)을 넘으면 자동으로 줄인 사본을 올립니다.
- **어느 달 영수증인지:** 영수증에 적힌 날짜로 정합니다. 그래서 영수증을 한 달 뒤에 찍어도 됩니다. 처리할 달이 끝나고 60일 안에 찍은 사진까지 봅니다(설정 `영수증_촬영_허용_일수`). 촬영 날짜는 영수증 날짜를 못 읽었을 때만 참고합니다.
- **Undefined인 Expense Type:** 주차는 `Parking & Toll`, 나머지는 `Other Staff Expenses`를 고르고 '확인 필요'로 표시합니다.
- **기타 설정:** `concur_settings.json`(메모장)에서 바꿉니다. 키워드, 분류 우선순위, Comment·Business Purpose 문구, Undefined일 때 유형, Concur 화면 문구가 있습니다.

## exe로 만들기

`build_exe.bat`을 더블클릭하면 `dist\ConcurAuto.exe`가 생깁니다. 콘솔 창 없이 바로 창이 뜹니다.
설정 파일, 병원 목록, `결과`·`실행기록` 폴더는 exe 옆에 생깁니다.
